1. Course Overview

This session introduced the Web Programming Sessional course and the technologies that will be used during the laboratory work.

The technologies mentioned in class are:

  • HTML: Creates the structure and content of a web page.
  • CSS: Controls the appearance and layout of a web page.
  • JavaScript: Adds interaction and dynamic behaviour to a web page.
  • PHP: Runs server-side code and can process data sent from a web page.
  • MySQL: Stores and manages data in a database.
Basic learning order: Start with HTML, then learn CSS and JavaScript. PHP and MySQL are used for server-side programming and database work.

2. Creating a GitHub Account

  1. Visit github.com .
  2. Select Sign up.
  3. Enter an email address, create a password and choose a username.
  4. Complete the verification steps.
  5. Verify the email address if GitHub asks you to do so.
  6. Sign in to the account.

3. Creating the Course Repository

A repository (repo) is a place on GitHub where project files, source code and documents are stored.

  1. Sign in to GitHub and click the + icon.
  2. Select New repository.
  3. Enter a repository name. The board appears to show 2304001_CSE_3154; use your own roll number if that number is not yours.
  4. Choose Public or Private, according to the course instruction.
  5. Click Create repository.

Suggested repository name: YOUR_ROLL_CSE_3154

5. Uploading the Lab Report and Code

Using the GitHub website

  1. Open your course repository.
  2. Open the relevant lab folder, or create it using Add file → Create new file. A folder can be created by typing a path such as Lab-01/README.md.
  3. Choose Add file → Upload files.
  4. Select the lab report PDF and the code files from your computer.
  5. Check that the correct files and folder paths are shown.
  6. Enter a short commit message, such as Upload Lab 01 report and code.
  7. Click Commit changes.

Important: Upload the actual source code files (for example, .html, .css and .js) as well as the PDF report. Uploading only screenshots or a PDF does not provide the source code.

6. What Does "Commit" Mean?

A commit is a saved record of changes made to the repository. A commit message briefly describes what was uploaded or changed.

Examples of useful commit messages:

  • Add Lab 01 HTML code
  • Upload Lab 01 report PDF
  • Update Lab 01 report and source files

7. Submission Deadline

According to the class instruction, the lab report PDF and code must be uploaded and committed to GitHub before the next lab day's deadline.

Deadline: Before 12:00 PM (noon) on the next lab day.

After committing, open the repository and confirm that the PDF and all required code files are visible.
